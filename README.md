#  Gestion de Budget

Application web simple pour suivre les revenus et les dépenses.

# Fonctionnalités

- Dashboard avec solde, revenus et dépenses
- Ajout de transactions
- Catégories
- Historique des opérations
- Recherche et filtre par type
- Suppression d'une transaction
- Suppression de toutes les transactions
- Sauvegarde automatique avec `localStorage`
- Design responsive

# Technologies

- HTML5
- CSS3
- JavaScript

# Installation

1. Téléchargez ou clonez le projet.
2. Ouvrez le fichier `index.html` dans votre navigateur.
3. Ajoutez vos transactions.

Aucun serveur n'est nécessaire pour la version locale.

## Important

Les données sont enregistrées uniquement dans le navigateur utilisé grâce à `localStorage`.
Elles ne sont pas synchronisées entre plusieurs appareils et ne constituent pas une sauvegarde bancaire.
